# AI 起步實驗室｜東京輕鬆遊

適合初次使用 AI、希望減少打字的學員。以科技風、大字與大按鈕呈現。

六題必做：選喜好聊旅行 → 排一天並追問 → 六頁簡報大綱 → 每頁內文 → 旅行封面 → NotebookLM 簡報。
六題選做：水豚旅行圖、角色設計、16格中文貼圖、依來源回答、行程資訊圖、簡報樣式。

- 喜好用按鈕選擇，自動帶入提示詞。
- 提示詞與追問直接複製，學員仍需在 AI 工具貼上並送出。
- 提供六頁示範內文，可直接作為 NotebookLM 來源。
- 文字與繪圖工具分別記住選擇；接續練習請使用原本對話。
- 六題必做進度與完成紀錄保存在目前瀏覽器。
- 語音輸入是選用方式，不是必要步驟。

開啟 index.html 即可使用，請保留整個資料夾。AI 服務需網路及帳號，本站不代為生成或傳送內容。NotebookLM 功能與額度依帳號及當時介面而異。

本機預覽：在上層資料夾執行 `python3 -m http.server 8768 --bind 127.0.0.1 --directory output`。

東京旅行內容是課堂練習構想，日期、票價、營業時間及路線仍需查證。

# AI 起步實驗室｜東京旅行篇

初次使用 AI 的學員適用，12 題、4 章：破冰、文字與簡報內容、圖像與貼圖、NotebookLM。

開啟 index.html 即可使用，請保留整個 output 資料夾。網站本身不需要連網；開啟 AI 工具時需網路與帳號。

- index.html：首頁與練習介面
- course.js：12 題提示詞、步驟與完成條件
- app.js：切換練習、複製與瀏覽器完成紀錄
- style.css：科技風與手機版樣式
- 東京旅遊練習素材.txt：課堂旅行設定
- 東京旅遊六頁示範內文.txt：NotebookLM 可直接使用的來源

提示詞可在畫面修改；切換題目仍保留本次修改，重新整理會回復原始提示詞。完成紀錄保存在目前瀏覽器。頁面沒有代為生成內容或上傳資料。

旅遊路線屬練習構想，沒有已查核的即時票價、班次或訂位資訊。NotebookLM 功能說明與官方連結查核於 2026-09-24，功能依帳號與當時介面為準。
